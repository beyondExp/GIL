# Security Policy

## Supported Versions

This project is currently **best-effort** community supported.

## Reporting a Vulnerability

- If you believe you found a security vulnerability, please **open a GitHub issue** titled **`[SECURITY] ...`**.
- If the report contains sensitive details, redact them and ask maintainers to provide a private contact channel.

## Hard rules for contributors

- Never commit secrets (API keys, tokens, private endpoints) to the repository.
- Keep large binary artifacts out of git (datasets, checkpoints, recordings). Use the `assets/` folder (gitignored).
