# Scripts

This folder contains many one-off experiments. For newcomers, start here:

- `bringup.ps1`: **single entrypoint** to start the stack (controls + Isaac + UI)
- `demo_warehouse_world.ps1`: Isaac warehouse preset + sets a `world_anchor`
- `run_isaac_h1_maze_real.ps1`: Isaac maze preset (Kit extensions)

Everything else is best treated as **experiments** unless referenced by docs/tests.
